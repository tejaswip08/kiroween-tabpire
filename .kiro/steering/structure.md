# Structure

```
entrypoints/
  background.ts            toolbar badge (starving count), refreshed every minute by an alarm
  newtab/                  "The Crypt" new tab page
    App.tsx, main.tsx      page root; styles.ts imports fonts and every stylesheet in cascade order
    components/            header, stats, cards, search, buttons, icons (custom gradient SVGs, no icon library)
    hooks/                 React hooks for the page (sizes, exits, toasts, suggestions)
    layers/                the two WebGL canvases: scene/ (graveyard and themes/), portraits/ (the card vampires)
    styles/                plain CSS; tokens.css holds every colour, per theme
  bloodbank/               the Blood Bank page
  popup/                   the toolbar popup
lib/                       pure logic, no React; browser APIs only in store.ts, tabs.ts, nav.ts, badge.ts and friends
  hunger.ts                tab states, hunger, memory estimates, Dawn targets (no browser APIs, time passed in)
  store.ts                 owns browser.storage.local
  tabs.ts                  Stake, Coffin, Crypt, Garlic, Resurrect, Dawn
  themes.ts                theme palettes, THEME_IDS, DISABLED_THEMES, ENABLED_THEME_IDS
  cardFit.ts               how many cards fit and at what scale
  tips.ts                  every text of the rich hover tips and the card hover quote
  bloodbank.ts             what the Blood Bank page shows (pure)
  scene/                   pure 3D layout data and maths (camera, sky, moon, layouts); uniqueScenes/ has one builder per theme
demo/                      Vite web demo: the real pages against lib/fakeBrowser.ts and sample tabs (demo/src/seed.ts)
public/models/             CC0 GLB models (Kenney, KayKit, Quaternius) and vampire.glb, with licence files
public/icon/               extension icons (generated by tools/make-icons.mjs)
tests/                     Vitest tests; tests/ui/ for React and three tests, tests/fixtures/ for recorded data
tools/                     small Node scripts (icons, CSS animation check, layout check)
build/                     Vite plugins shared by the extension and the demo
docs/screenshots/          README images
.kiro/                     steering, specs (one folder per spec) and hooks
```

## Naming
- React components: `PascalCase.tsx`, one main component per file. Hooks: `useThing.ts`.
- Pure modules: `camelCase.ts` in `lib/`. Tests mirror the module name: `lib/cardFit.ts` -> `tests/cardFit.test.ts`.
- Theme ids: `crypt`, `pumpkin`, `forest`, `frost` (enabled), `bloodmoon`, `castle` (disabled). A theme's scene builder is
  `lib/scene/uniqueScenes/<theme>.ts`; its components are in `entrypoints/newtab/layers/scene/themes/`.
- CSS classes: lowercase, dash-separated, named after the component (`.card-actions`, `.header-btn-dawn`).
- UI text uses plain words ("Add page", not "haunt"); code names may keep the spooky names (`Haunts.tsx`).
