# Style rules

- Cute-spooky 3D Halloween look. Mood is cute, not gory.

- Never change the Crypt theme layout once built.

- The moon is a plain red glowing disc. No face, no eyes.

- Use plain words in the UI ("Add page", not "haunt").

- CSS animations only use transform and opacity (keeps 60 fps).

- Never make the graphics blurry or lower quality to gain speed.

- Fonts: Grenze Gotisch for titles, Sora for labels, Outfit for body text.
